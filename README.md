# NULLSTORM 3D – Web-Version

Spielen im Browser: **https://edolas27.github.io/nullstorm/**

- Handy: Link öffnen, quer halten. iPhone: Teilen > «Zum Home-Bildschirm», Android: Menü > «App installieren». Dann läuft es im Vollbild wie eine App, nach dem ersten Laden auch offline.
- PC: Maus/Tastatur oder Controller.
- Die Web-Version ist Einzelspieler. Für Multiplayer das Setup am PC installieren und dort «Multiplayer > Hosten» wählen.
